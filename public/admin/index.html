Test mode is the default. Never paste provider secret keys into this dashboard or commit them to GitHub. Put Paystack and Flutterwave secrets in Render Environment. A green gateway indicator means the server has a key for the current mode; you must still complete test transactions.
Payment gateway readiness

Webhook URLs: https://teampeach.org/api/payments/webhooks/paystack and https://teampeach.org/api/payments/webhooks/flutterwave. Configure each in its provider test dashboard. Set the Flutterwave webhook secret hash in Render as FLW_SECRET_HASH.

Membership plans

Create monthly plans with a usage-credit allowance. Activate the plan, then sync it with each payment provider you want to offer. Changing a plan with active subscribers is blocked; create a new plan for new pricing.

Product catalogue and tool licences

Set one-time software licence pricing, optional hosted access, credits per hosted run, member discount, source-code delivery details and basic setup hours. Product visibility and hosted availability are separate.

Credit top-up packs

Top-ups are a separate one-time purchase. Keep the value and price transparent so customers know what they are buying.

Customers and credit adjustments

Manual adjustments are written to the credit ledger with the admin and reason, so changes are auditable.

Purchased licences and deployment queue

Update code delivery, setup progress and deployment status. For the initial release, customer deployments are recorded and assisted manually; this does not automatically create a separate Render service.
