HOW TO READ A RESULT

Four source signals.
Not four interchangeable statuses.

Each provider describes a different observation. TeamPeach preserves the source label so a match is not mistaken for a definitive registration or availability status.

01

Newly observed

Appeared in Webamon's newly observed zone-file data. This is not a confirmed registrar creation timestamp.

02

Removed

Appeared in Webamon's removed-domain data. Removal does not prove expiry or current availability.

03

Expired

Appeared in WhoisFreaks' free public expired-domain list. Its coverage is limited.

04

Dropped

Appeared in WhoisFreaks' free public dropped-domain list. A match still needs current registration verification.

Important interpretation

A match tells you which current feed contains a domain. A no-match does not prove that a domain is safe, unregistered or available. This first version performs exact domain lookups; it is not yet a bulk search, RDAP availability checker or threat verdict.

COMMON QUESTIONS

Domain lookup, clearly explained.

Does a removed domain mean I can register it?

No. The removed feed is a zone-file observation, not a registrar availability confirmation. A current RDAP check and registrar verification are needed.

Does a no-match mean the domain is safe?

No. It means only that this exact domain was not present in the four datasets in the latest snapshot.

Does a lookup consume AI credits?

No. Domain lookups, filtering and ordinary data retrieval do not consume TeamPeach AI credits.

How often is the data updated?

The collection pipeline runs daily at 7:45 a.m. Lagos time. Source update delays or failed provider downloads can affect the latest available snapshot.
